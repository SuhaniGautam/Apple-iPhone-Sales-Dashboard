# Apple-iPhone-Sales-Dashboard
AI-Assisted Sales Dashboard using Microsof# 🍎 Apple iPhone AI-Assisted Sales Dashboard

An interactive sales dashboard created using Microsoft Excel to analyze Apple iPhone sales performance.

## 📊 Project Overview

This project analyzes iPhone sales data to understand sales performance across different models, cities, and sales channels.

## 🔍 Key Insights

- Identify the highest-selling iPhone models
- Analyze sales performance by city
- Compare Online and Retail sales
- Track monthly revenue trends
- Identify products with high unit sales
- Support better inventory and sales decisions

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Analysis
- AI-Assisted Insights

## 📁 Project File

The Excel workbook contains the sales data, analysis, and interactive dashboard.

To convert raw iPhone sales data into simple and useful business insights through an Excel-based dashboard.t Excel
